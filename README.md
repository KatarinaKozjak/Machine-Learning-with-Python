
# Machine Learning with Python

## Overview

This repository contains practical machine learning exercises completed as part of Artificial Intelligence coursework at the Faculty of Organizational Sciences, University of Belgrade.

The exercises focus on applying machine learning algorithms to data analysis, classification, regression, clustering, and neural network problems.

## Algorithms

| Algorithm | Area |
|---|---|
| Linear Regression | Regression |
| Decision Trees | Classification |
| K-Nearest Neighbors (KNN) | Classification |
| Neural Networks (MLPClassifier) | Classification |
| Clustering | Unsupervised Learning |

## Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Repository Structure

Each folder contains Jupyter Notebook exercises related to a particular machine learning method, along with task descriptions where available.

## Learning Objectives

- Data preparation and exploratory analysis
- Applying supervised and unsupervised learning algorithms
- Training and evaluating machine learning models
- Visualizing and interpreting results

## Academic Context and Attribution

These exercises were completed as part of university coursework and exam preparation. Some materials are based on examples provided by the Artificial Intelligence course at the Faculty of Organizational Sciences.

## Dataset Availability

Some datasets are not included. Refer to individual notebooks and task descriptions for dataset requirements and availability.
